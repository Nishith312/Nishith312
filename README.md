I'm **Nishith Prajapati**, Lead Flutter Developer at **Yunawise Technologies**. My work spans parking, fintech, healthcare, sports, and field-force tools, with **100k+ combined downloads** across published apps.

- 💬 **Ask me about:** Flutter architecture (GetX / Bloc), 60fps performance rescue, store submission
- 🏠 **Based in:** Ahmedabad, India (IST)
- 🤝 **Open to:** Contract or full-time work, remote anywhere
